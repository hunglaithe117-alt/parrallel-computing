# Benchmark charts

Generated by `python3 charts/make_charts.py` (Python 3 stdlib only: no numpy/matplotlib/pandas, no network) purely from the CSVs below. No number here is hand-written.

## 0. Data sources and context

- `results/results.csv`: 64 rows (required).
- `results/results_t6.csv`: 64 rows (optional THREADS=6 run).
- `results/scaling.csv`: 48 rows (optional).
- `n` (elements) is shown per kernel/chart and comes from the CSV. The `class` column (`single-thread`/`multi-thread`) marks the thread class of each row; the multi-thread row pass uses the run's THREADS setting, which is recorded in `docs/RESULTS.md`, not in `results.csv`, so no thread count is invented here.

> Caveats (from the benchmark contract): the element-wise and reduction kernels here are typically **memory-bound**, so SIMD or threading speedups are limited by bandwidth, not arithmetic. Differences **under ~15% are ties** (noise band: pinned medians still vary ~10-15% run to run); never narrate an ordering inside the band as an effect. Cross-language comparison is **time-only**: input generators differ by design, so checksums are validated within a language, never across languages.
