Benchmark charts

Generated by python3 charts/make_charts.py (Python 3 stdlib only) purely from the CSVs. No number here is hand-written.

Caveats (from the benchmark contract): the element-wise and reduction kernels here are typically memory-bound, so SIMD or threading speedups are limited by bandwidth. Differences under ~15% are ties (noise band); never narrate an ordering inside the band as an effect. Cross-language comparison is time-only: input generators differ by design, so checksums are validated within a language, never across languages.

Sources: results/results.csv (64 rows); results/results_t6.csv (64 rows); results/scaling.csv (48 rows). n is shown per chart from the CSV; thread class comes from the CSV class column.
